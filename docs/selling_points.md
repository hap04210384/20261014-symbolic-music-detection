**状态：讨论稿 v0.1（2026-10-11）——经作者确认后冻结，实验设计以此为准反向推导。**

## 0. 一句话卖点（One-liner）

> **第一个对 AI 音乐训练数据复制给出"可证明召回保证"的检测系统——免阈值、anytime、容噪，且第一次在百万文件语料上做到了精确检测。**

关键词拆解（这也是标题和摘要的词源）：
**provable recall** × **threshold-free** × **anytime** × **noise-tolerant** × **million-file scale**

## 1. 卖点金字塔

> **为什么头条不是"位图加速挖掘"？**（2026-10-11 与作者讨论后固化）
> 位图（BMMA）是发动机不是卖点：① 位图挖掘在 FIM 文献中早有先例
> （BitFIM 类），头条写它会被判为工程增量；② A 论文（EAAI 在审）已以
> AnyFIM/TensorFIM 引擎（含位图加速）为核心，B 再以此当头条会造成两篇
> 重叠度问题；③ 检测任务与保证才是 B 独有的新信息。
> 位图在本文中的位置：Method 4.2 方法组件 + 标题副题（"Bitmap-Accelerated"）
> + E4/E5 实验证据——戏份足，但不站 C 位。

```
                ┌─────────────────────────────┐
     塔尖        │ SP1  保证 × 规模的交集（首创）  │  ← 标题级卖点
                ├─────────────────────────────┤
     主体        │ SP2  零调参免阈值 anytime     │  ← 系统级卖点
                │ SP3  有界容噪 + 保证不塌        │  ← 方法级卖点
                ├─────────────────────────────┤
     底座        │ SP4  混合级联（精确+神经互补）  │  ← 实验级卖点
                │ SP5  可呈证证据输出            │  ← 应用级卖点
                └─────────────────────────────┘
```

**核心逻辑：SP1 = SP2 × SP3 × SP4 的交集，不是第四个独立贡献。**
单独的"保证"（小规模精确匹配，SIATEC 家族早就有）和单独的"规模"
（n-gram 哈希也能跑百万级，但没有保证、没有定位）都不新；
**"有保证的精确检测能跑百万级"**这个交集才是空白——方案中
"方法停在百首时代，数据已进入百万时代"指的就是这个交集。

## 2. 各卖点详表

### SP1（塔尖）：可证明召回 × 百万级规模的交集——首创

- **陈述**：对 AI 生成音乐的符号复制检测，我们给出可证明的召回下界
  （免阈值 anytime 调度：任意停止时刻，已输出命中集对搜索空间完备；
  容噪 ≤k 时召回下界成立），并把这一保证首次带到了 143 万文件的语料规模。
- **为什么以前没人做到**：
  - SIATEC/COSIATEC/SIARCT-CFP 家族：精确但无召回概念、千首级即不可行；
  - n-gram/哈希类：能跑大规模，但近似、需调阈值、无完备性；
  - 神经嵌入类（MelodySim/MERT）：语义强，但近似 + 阈值截断 + 不可解释，
    论文自己承认"no generally accepted definition of plagiarism"。
- **审稿人攻击预案**：
  - 攻："召回保证只是理论游戏" → 备：E2/E3 用实测召回-噪声曲线与
    anytime 质量-时间曲线证明保证不是空的；
  - 攻："音乐版权诉讼看实质性相似，verbatim 不重要" → 备：RIAA/Koda
    诉状与 expert report 恰恰把 verbatim/substantially similar copies 列为核心举证
    （引用方案 7.3 合规与法律背景）；
  - 攻："n-gram 哈希也能做" → 备：E4 同规模对比吞吐与定位精度，且哈希无
    容噪保证、无 anytime 性质。
- **对应实验**：E2（保证验证）、E3（anytime）、E4（规模）、E1（全面对比）。

### SP2（主体上）：零调参的免阈值 anytime 系统

- **陈述**：整个系统无相似度阈值、无支持度阈值，无需调参即可运行；
  用户任意时刻停止，即得到当前完备结果与召回下界。
- **为什么新**：抄袭检测文献中所有方法都依赖相似度阈值（这是其主要
  误报来源和跨数据集失效原因）；anytime 性质使系统可以嵌进生成流水线
  做实时筛查（Suno 式输出过滤的时间预算场景）。
- **对应实验**：E3（anytime 曲线）+ E5（免阈值 vs 阈值化消融）。

### SP3（主体下）：有界容噪，且保证不塌

- **陈述**：单边扩展的有界容错变体——每匹配位置容忍 ≤k 个事件偏差，
  证明噪声 ≤k 时召回下界仍然成立；k 是系统唯一参数，且其语义是
  "噪声上界"而非调出来的超参。
- **为什么新**：容噪匹配在音乐信息检索里不新（SIARCT-CFP 的 fingerprint、
  编辑距离类），但**带证明的容噪**没有；容噪把"符号精确"从短板变成卖点——
  它使方法能处理真实 AI 音频输出的转录噪声。
- **对应实验**：E2（召回-噪声曲线，理论界 vs 实测）+ E1 变换⑥（转录往返）。

### SP4（底座上）：精确层与神经层互补的混合级联

- **陈述**：精确层抓 verbatim/near-verbatim（可呈证），神经嵌入层抓语义
  相似；级联混合在两族正样本上同时优于任一单层——检测器之间不是替代关系。
- **为什么新**：现有工作把两类方法当竞争对手比高下；我们证明它们是
  流水线上的上下工序，并给出级联协议。
- **对应实验**：E7（混合 P-R 曲线）+ E6 真实案例。

### SP5（底座下）：可呈证的证据输出

- **陈述**：每个命中输出确定性定位（片段对齐图）+ MD5 验证协议
  （结果可复现、可呈法庭）；可解释性是构造带来的，不是事后可视化。
- **为什么新**：神经方法的 decision matrix 是模型解释的近似；我们的证据
  是数学对象的直接展示。
- **对应实验**：E6 案例研究（MCIC + sound-alike，乐谱对照图）。

## 3. 非卖点声明（Discussion 里主动写，防止审稿人替我们写）

1. **不做法律判定**：系统是筛查层（screening layer），输出证据不输出
   "抄袭/未抄袭"结论——实质性相似判断留给法律程序。
2. **不抓"灵感级"相似**：移调改节奏换和声的实质性相似超出 verbatim/
   near-verbatim 范围，由 SP4 的神经层覆盖但不提供保证。
3. **不替代数据许可审查**：检测复制 ≠ 判定训练是否合法（fair use 是
   法律问题）。
4. **符号域为主、音频经转录**：不声称端到端音频复制检测；定位为
   与音频域嵌入级联的符号筛查层。

## 4. 价值陈述（Value Statement）

> 卖点回答"我们做了什么新的"，价值回答"世界因此多了什么"。三层价值，
> 分别对应论文 Introduction 前两段、Discussion 的应用一节、与政策讨论。

### 学术价值
- 把"可证明召回"范式从安全领域（extraction attack / membership inference）
  进口到音乐检索：MIR 相似度研究二十年来只有"嵌入+阈值+AUC"一条路，
  本文给出带保证的评价新标准；
- 公共资产：检测协议 + planted-copy 基准（后来者须在此协议上对比）；
- 可推广模板：免阈值 anytime + 有界容噪 + 验证协议，适用于文本复用、
  代码抄袭、生物序列等筛查任务。

### 产业价值（"为什么是现在"的答案）
- 授权时代刚需：UMG×Udio、Warner×Suno 和解后，2026 年授权平台必须证明
  "输出不复制训练库"；Suno 披露已部署相似性过滤但方法不公开；
- 买方明确：平台方（输出过滤）、版权集体管理组织（监测）、独立音乐人（自查）；
- 不对称优势：公开 + 可验证（MD5）+ 有保证——闭源私有过滤器永远给不出
  召回下界，确定性证据可进法庭而神经相似度分数不能。

### 社会价值
- T2 实验产出"训练重复率→记忆化→检出率"定量曲线：AI 音乐版权争论目前
  建立在 anecdotes 上，这是首个 ground-truth 可控的公开证据链，直接影响
  政策制定，也是可进课堂的公共品。

### 价值的诚实边界（Discussion 必须主动写）
- 筛查层不是法官：价值是降低举证成本，不是判定侵权；
- 平台可能自建闭源过滤器；防御姿态 = 公开 + 可验证 + 保证。
